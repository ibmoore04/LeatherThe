# Leather The — Luxury B2B & Wholesale Homepage

Official modern digital showroom and B2B wholesale portal for **Leather The** (Small Industrial Estate, Sialkot, Pakistan).

## 🌟 Highlights
- **Full 20-Product Catalog**: All products from the catalog (LT-01 to LT-20) with interactive category filter tabs and real-time SKU search.
- **1-Click WhatsApp Order Builder**: Implements the brand's 3-step ordering process into an automated slide-out quote drawer with direct prefilled WhatsApp integration (+92 342 4974551).
- **Luxury Editorial Design**: Tailored oxblood burgundy (`#420f1e`), antique gold (`#d4af37`), and stitched leather dashed frames inspired by the official catalog.
- **Bespoke & OEM Studio**: Interactive configurator for leather types, hardware finishes, and embroidery techniques.
- **Tactile Sound & Micro-Interactions**: Custom cursor, 3D card tilt physics, smooth reveal animations, and Web Audio API feedback.
